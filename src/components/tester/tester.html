Note
Input labels are DS4 button names; output labels are Alpakka's own profile fields (Select 1/Start 1/Select 2/ Start 2), since that side reflects what the profile resolved to, not the DS4 report. Select 2 covers both Capture and Share (the firmware ORs them into one field before either reaches the profile, so there is nothing distinct to show for Share). Home comes from the passthrough guide press, tracked separately since it has no per-profile field like the rest. Extra buttons (EL1-4/ER1-3) are the modded switches next to the bumpers -- unrelated to passthrough, shown here only because this page is a convenient place to watch live button state. They read the physical switch directly, so they stay live whether the switch is left in "inherit" mode (driven through the stock dpad/select/start section above) or diverted to its own actions.
